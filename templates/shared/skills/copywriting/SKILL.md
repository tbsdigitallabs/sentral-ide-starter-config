# Copywriting

## Before writing

1. Read `.agents/product-marketing-context.md` if it exists
2. If missing, run `product-context` or ask 2–3 focused questions

## Principles

- Lead with outcome for the reader, not feature lists
- Specific beats vague; proof beats adjectives
- One primary CTA per section
- Short sentences; cut filler

## Structure (landing page)

1. Headline — clearest promise
2. Subhead — who it's for + how
3. Proof — metrics, logos, quotes (only if real)
4. CTA — action + friction reducer

## Deliver

- Provide paste-ready copy unless asked for options
- Offer 2 headline variants only when useful

## Do not

- Invent testimonials or metrics
- Use hype words without substance (revolutionary, cutting-edge)
