# SEO audit

## Scope

Review one page or site section at a time.

## Checklist

### Indexability
- [ ] No accidental noindex on important pages
- [ ] Canonical URLs set where duplicates exist
- [ ] robots.txt and sitemap reasonable for prod

### On-page
- [ ] Unique title (50–60 chars target) and meta description
- [ ] One H1 aligned with search intent
- [ ] Logical H2/H3 structure
- [ ] Internal links to related content

### Content
- [ ] Primary keyword used naturally in title, H1, intro
- [ ] Alt text on meaningful images
- [ ] No thin or duplicate boilerplate blocks

### Technical (flag only)
- Core Web Vitals risks (LCP, CLS)
- Broken links or redirect chains

## Output format

1. **Summary** — 2 sentences
2. **Issues** — severity (high/medium/low), finding, fix
3. **Quick wins** — top 3 changes by impact

## Do not

- Recommend keyword stuffing
- Promise ranking outcomes
